# Olfah — Motherhood Support Platform

## Setup

1. **Install dependencies**
   ```bash
   npm install
   ```

2. **Add your API key** — copy `.env.example` to `.env` and fill in your Anthropic API key:
   ```bash
   cp .env.example .env
   # then edit .env and paste your key
   ```

## Development

```bash
npm run dev
```

## Production build & start

```bash
npm run build
npm start
```
